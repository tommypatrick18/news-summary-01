# News Summary Entry - November 11, 2026

This repository contains a Python 3 program and a news summary data file.

### main.py
The script main.py is a Python 3 program that utilizes only the standard library. It reads the file summary.txt from its own directory and writes a byte-exact copy to entry.txt in the directory specified by the MAKEFUN_OUTPUT_DIR environment variable. If the environment variable is not set, the script defaults to using the /output directory.

### summary.txt
The file summary.txt contains a one-paragraph summary of the world's news for Wednesday, 11 November 2026. This summary includes exactly 15 stories and has a total length of 1,996 characters.
