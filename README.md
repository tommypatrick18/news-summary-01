# Summary of Events: 11 November 2026

## Program: main.py
The `main.py` script is a deterministic utility that reads `summary.txt` from its local directory and performs a byte-exact copy of its content to a file named `entry.txt`. The destination folder is specified by the `MAKEFUN_OUTPUT_DIR` environment variable, defaulting to `/output` if the variable is not defined.
